forcefield
==========

`forcefield` is an opinionated agent sandbox tool for agentic AI usage.

# Goals

`forcefield` is highly opinionated, highly specialized for few specific
agentic AI usage and is in general not recommended for production outside
this narrow scope.

`forcefield` is largely a learning exercise. Code is developed with AI assistance
for the scaffolding, not for the key areas

`forcefield` has a very strict and peculiar definition of "done" which
is likely to be unfit for many use cases. It is published hoping it is
useful, but has no ambitions of generalizability.
Features are added on a strictly need-by-need basis.

If you find `forcefield` _almost_ good enough for your usecase, you
are recommended to fork it and extend as you see fit.
If you need a production-ready alternative, please consider some of the
ones listed below.

# Alternatives

If you are on the lookout for a production-ready, robust, generic sandboxing tool,
you may want to consider (alternative listed based on author's knowledge and not
sorted on any criteria)

- [codex sandbox crate](https://github.com/openai/codex/blob/main/codex-rs/linux-sandbox/README.md)
- [nono](https://github.com/nolabs-ai/nono)
- [OpenShell](https://github.com/NVIDIA/OpenShell)
- [bubblewrap]((https://github.com/containers/bubblewrap)

# AI usage

AI is used for assistance, not to replace key human effort. Learning is part of the goals.
